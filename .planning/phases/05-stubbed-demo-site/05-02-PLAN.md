| Boundary | Description |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Information disclosure | demo/assets images (EXIF/GPS) | high | mitigate | Pipeline re-encodes from raw pixels and the downscale writes webp without metadata; fixtures test asserts no exif/icc/xmp on vision.jpg, thumb and every crop |
| T-05-09 | Information disclosure | demo/fixtures/discogs.json (token, username, image URLs) | high | mitigate | RecordedCandidate key allowlist drops thumbUrl/masterId/URLs; recorder self-check compares the JSON against every secrets value (key names only in errors) and rejects 'http'/thumb; fixtures test re-checks on every run |
| T-05-10 | Tampering | owner's Discogs collection via the recorder | high | mitigate | GET-only guard limited to /database/search and /releases/; recorder gated behind DEMO_RECORD=1 and never part of pnpm test |
