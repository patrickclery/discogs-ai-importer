## Phase Goal

**As the** owner cataloguing my discs, **I want to** launch the app locally with one command and set up my credentials, **so that** all state lives in one portable data folder and background work survives restarts and hot reloads.

**This plan's slice:** the owner's queued work finishes exactly once even if the app is killed, restarted, hot-reloaded or started twice, and the data folder can be copied to another place and keeps working.

<objective>
Harden the tracer's queue and worker into the restart-safe, single-worker system FOUND-04 promises, add the traversal-guarded path resolver FOUND-02 needs, and prove ROADMAP success criteria 3 and 4 with end-to-end scripts.

Purpose: Phase 2 enqueues paid-plan Claude calls and Phase 3/4 Discogs writes on this queue; double execution or lost jobs would cost money and create duplicate collection entries.
Output: retry/backoff/recovery/dedupe/timeout in queue.ts and worker.ts, lease.ts, resolveData, three verify scripts.
</objective>
