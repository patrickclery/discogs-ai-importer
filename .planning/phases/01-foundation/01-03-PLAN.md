**As the** owner cataloguing my discs, **I want to** launch the app locally with one command and set up my credentials, **so that** all state lives in one portable data folder and background work survives restarts and hot reloads.

**This plan's slice:** the owner saves the Discogs app credentials on the settings page and afterwards only ever sees them masked; the keys stay on this computer, outside the data folder and out of git.

Purpose: Phase 3 needs these credentials for OAuth; the owner must be able to copy or share the data folder without leaking keys.

Reading happens at call time with readFileSync plus a zod record-of-strings parse: a missing file means {}; invalid JSON or a non-string value throws SecretsFileError whose message never includes file content.
