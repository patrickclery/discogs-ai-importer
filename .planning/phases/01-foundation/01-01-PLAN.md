## Phase Goal

**As the** owner cataloguing my discs, **I want to** launch the app locally with one command and set up my credentials, **so that** all state lives in one portable data folder and background work survives restarts and hot reloads.

(Derived word-for-word from the ROADMAP Phase 1 Goal line, which is not in user-story form. Flagged: run `/gsd-mvp-phase 1` to restate it if this framing is wrong.)

**This plan's slice (walking skeleton, tracer):** the owner runs `pnpm dev` or `pnpm start`, the app comes up on http://127.0.0.1:3000 with a migrated `data/app.db`, and a test job POSTed to `/api/dev/jobs` is stored in SQLite, run by the single background worker and reported by `GET /api/status`. Plan 01-05 puts the **Queue test job** button and the header status on this same path; Plan 01-06 adds the Host/Origin guard, the unit-test harness and the README.

**Scope note (revision 1, checker scope_sanity):** the old single tracer task (about 70 files) is split. This plan keeps only the thinnest path through every server layer plus the scaffold it needs; the shell UI and the 15 shadcn primitives moved to Plan 01-05, and the proxy, test harness, toolchain pins and docs moved to Plan 01-06. Of the 31 files below, 13 are scaffold or tool output (create-next-app, pnpm, drizzle-kit) and 18 are small hand-authored modules whose paths later plans import; the estimate is 55k tokens against the 100k smart-zone budget.
