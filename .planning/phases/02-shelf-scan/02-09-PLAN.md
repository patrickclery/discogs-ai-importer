## Phase Goal

**As the** owner cataloguing my CDs, **I want to** drop shelf photos and see every detected spine as a horizontal crop next to the AI-extracted fields, which I can correct, **so that** misreads are easy to see and fix and each photo costs exactly one Claude call.

(Derived from the ROADMAP Phase 2 Goal line and the PROJECT core value; flagged in Plan 02-01.)

**This plan's slice:** the owner corrects any field right under its crop; the change saves when they leave the field, survives a reload, keeps Claude's original read, and can be reverted. Low-confidence reads are marked so the owner knows where to look.

<objective>
Make spine fields editable: PATCH route and field persistence that never touch ai_value, the SpineField component with autosave, revert, confidence warnings and save states, and the card's worst-field and edited badges.

Purpose: REV-02 and D-08..D-10: edits are stored separately from the AI output and are never lost to polling.
Output: fields API and persistence with tests, SpineField, WorstFieldBadge, textarea, card wiring, and a verify-scan PATCH step.
</objective>
