## Phase Goal

**As the** owner cataloguing my CDs, **I want to** drop shelf photos and see every detected spine as a horizontal crop next to the AI-extracted fields, which I can correct, **so that** misreads are easy to see and fix and each photo costs exactly one Claude call.

(Derived from the ROADMAP Phase 2 Goal line and the PROJECT core value; flagged in Plan 02-01.)

**This plan's slice:** after a re-scan, spines Claude no longer found but that carry the owner's edits are shown as "No longer detected" and can be re-attached to a newly found spine or dismissed, so no correction is ever silently lost.

<objective>
Resolve D-16 orphaned spines: list them, re-attach one to a newly found spine (moving its edits), or dismiss it.

Purpose: D-16 forbids dropping edited spines silently, so the owner needs a way to finish them.
Output: orphan server functions and routes with tests, the Re-attach dialog and Dismiss confirm, orphan sections on cards, and e2e steps in verify-rescan.
</objective>
