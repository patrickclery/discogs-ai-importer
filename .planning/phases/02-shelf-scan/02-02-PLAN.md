## Phase Goal

**As the** owner cataloguing my CDs, **I want to** drop shelf photos and see every detected spine as a horizontal crop next to the AI-extracted fields, which I can correct, **so that** misreads are easy to see and fix and each photo costs exactly one Claude call.

(Derived from the ROADMAP Phase 2 Goal line and the PROJECT core value; flagged in Plan 02-01.)

**This plan's slice (D-01 spike, measurement):** using the production modules from Plan 02-01, measure the CLI's real pixel space against known boxes, compare Opus and Sonnet at two effort levels on every spike photo, propose the constants the Plan 02-04 freeze decides, and lock geometry, normalization, parsing and argv with tests that use only recorded fixtures.
