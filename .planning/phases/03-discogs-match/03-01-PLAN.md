## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

(Derived from the ROADMAP Phase 3 Goal line and the PROJECT core value; the Goal line is not in user-story form, so this framing is flagged in "Planner assumptions".)

**This plan's slice:** a connect started from the app goes to discogs.com, comes back through the callback and saves the owner's Discogs sign-in locally. Every request goes through one paced gate with the project User-Agent, and the client can only read. Plan 03-02 puts the Connect button and the Settings card on top of these routes; Plan 03-04 adds the paste-code fallback; Plan 03-03 adds the searches that use this connection.

Purpose: DISC-01 (connect), plus the DISC-02 gate from the first call site onward. D-01 to D-05 land here; D-06's 60 s default pause is built into the client.
Output: src/server/discogs/{config,oauth,gate,client,auth,connect}.ts, client.test.ts, two routes, test/fixtures/fake-discogs.mjs, scripts/lib/discogs.ts and scripts/verify-discogs.ts.
