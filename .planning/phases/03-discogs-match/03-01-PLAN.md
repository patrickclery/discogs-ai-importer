## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

(Derived from the ROADMAP Phase 3 Goal line and the PROJECT core value; the Goal line is not in user-story form, so this framing is flagged in "Planner assumptions".)

**This plan's slice:** the owner saves the Discogs consumer key and secret, clicks Connect Discogs, approves on discogs.com and comes back to "Connected as {username}". Every request goes through one paced gate with the project User-Agent. Plan 03-02 finishes the Settings card (test, disconnect, notices, reconnect). Plan 03-03 adds the searches that use this connection.

3. src/server/discogs/oauth.ts (RESEARCH Code Examples, PLAINTEXT, RFC 5849): percentEncode = encodeURIComponent plus the characters !'()* as uppercase %XX; buildOAuthHeader({ consumerKey, consumerSecret, token?, tokenSecret?, callback?, verifier?, nonce?, timestamp? }) returns 'OAuth ' plus k="v" pairs joined by ', ' for oauth_consumer_key, oauth_nonce (crypto.randomBytes(16) hex unless given), oauth_signature_method PLAINTEXT, oauth_timestamp (seconds unless given), oauth_version 1.0, oauth_signature = percentEncode(consumerSecret) + '&' + percentEncode(tokenSecret ?? 4. src/server/discogs/gate.ts (RESEARCH Pattern 2, D-05, D-06): a singleton on globalThis key __discogsGate holding nextAt, intervalMs (default intervalForLimit(60) = 1112) and pausedUntil, with an injectable clock for tests. intervalForLimit(limit) = Math.ceil(60000 / (limit * 0.9)). acquire(signal) waits (abortable, timers unref'd) until max(nextAt, pausedUntil), then sets nextAt = now + intervalMs. observe(headers): limit = X-Discogs-Ratelimit when it parses as a positive integer (else ignored), remaining = X-Discogs-Ratelimit-Remaining; intervalMs = intervalForLimit(limit), doubled when remaining is a number below Math.ceil(limit * 0.1); no headers leaves intervalMs as it is. pause(ms) sets pausedUntil = max(pausedUntil, now + ms). pausedUntil() returns the value or null when it is in the past. parseRetryAfter(value, now) returns milliseconds for integer delta-seconds or an HTTP-date (delta rounded up to whole seconds), clamped to 1 000-300 000, and null for anything else (absent means the caller uses 60 000).

5. src/server/discogs/client.ts discogsFetch({ method = 'GET', path, query?, form?, auth: 'none' | 'consumer' | 'request' | 'oauth', token?, tokenSecret?, callback?, verifier?, signal? }, deps = { fetchImpl: fetch, gate: discogsGate() }): resolves the consumer key and secret through getSecret and the stored token through getDiscogsAuth when auth is 'oauth'; refuses before any request unless method is GET, or method is POST with path exactly /oauth/access_token (phase prohibition: nothing is ever written to the owner's Discogs account); builds the URL from apiBase() with URLSearchParams; sends User-Agent DISCOGS_USER_AGENT, Accept application/vnd.discogs.v2.discogs+json and the OAuth header when auth is not 'none'; awaits gate.acquire, fetches with redirect 'error' and AbortSignal.any([signal, AbortSignal.timeout(20000)]), calls gate.observe(res.headers) before branching, reads the body with res.text() and tries JSON.parse (never assume JSON: OAuth errors are plain text with a form content type, some are 500 JSON). Classification: 2xx returns { status, headers, text, json }; 429 calls gate.pause(parseRetryAfter(...) ?? 60000) and throws DiscogsRateLimitedError carrying resumeAt; 401 throws DiscogsAuthError and, when auth is 'oauth', calls markAuthInvalid(); 404 throws DiscogsNotFoundError; other 4xx throw DiscogsRequestError; 5xx, fetch TypeError and timeouts throw DiscogsUnavailableError. Each error class sets this.name to its class name (callers compare by name, as worker.ts does for HMR). Error messages carry the HTTP status, the method and the path only, never headers, the query, the body or any secret, and nothing in this module logs the request init.
