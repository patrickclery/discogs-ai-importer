## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

**This plan's slice:** coming back from discogs.com always ends in a clear message. If discogs.com shows a code instead of bringing the owner back, they paste it on Settings and finish connecting; the callback URL is shown with a Copy button for the owner's port. No page ever carries a secret.

<objective>
Add the paste-code fallback (finish route and form), the ?discogs= result notices and the callback URL well to the Settings Discogs card from Plan 03-02, and pin the pending-connect store, the exchange fallback and the signer with unit tests plus a canary sweep of every page and route.

Purpose: DISC-01 (connect works even when discogs.com does not redirect back); D-01, D-02 (no secret reaches the browser), D-03 (callback URL shown for the A1 fallback).
Output: finish route, PasteCodeForm, DiscogsConnectNotice, CallbackUrlField, the amended card and settings page, auth/connect/oauth unit tests, and verify-discogs steps (g), (i), (j), (k) and (l).
</objective>
