## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

**This plan's slice:** when automatic matching misses, the owner opens "Search Discogs…" on a card, types a search or pastes a Discogs release link or number, checks the result against the crop, and adds the right one to that spine's candidates, where it stays on top.

<objective>
Build the Search Discogs dialog: the client-safe release-link parser, text and ref modes on the search route, the manual-search branch and the fetch_release handler on the discogs lane, the dialog's polling route and result covers, and the add-manual POST that copies from stored results.

Purpose: DISC-06; D-15 and the manual half of D-16.
Output: discogs-ref.ts, search route modes, fetch-release.ts, two dialog routes, the candidates POST, DiscogsSearchDialog, the matches trigger, tests and verify steps.
</objective>
