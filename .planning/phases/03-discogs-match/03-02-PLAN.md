## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

**This plan's slice:** the Settings Discogs card does everything the UI contract promises. The owner can test the connection, disconnect, reconnect after Discogs stops accepting the app, finish connecting with a pasted code when discogs.com doesn't bring them back, copy the callback URL, and see a clear message after coming back from discogs.com.
