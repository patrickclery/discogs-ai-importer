## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

**This plan's slice:** after correcting a spine's artist, title or catalog number, the owner sees that the matches are from the old values and can search again with one click. A search that failed can be retried the same way.

<objective>
Add the explicit re-search path: the fields-changed signal in the read model, POST /api/spines/{id}/search in 'again' mode with a fresh per-search dedupe key, and the Search again and Retry search buttons in the matches header.

Purpose: DISC-05 and D-14; the Retry action promised by D-06.
Output: the search route with route tests, enqueueExplicitSearch, fieldsChanged, the matches header actions and a verify-discogs-search step.
</objective>
