## Phase Goal

**As the** owner cataloguing my CDs, **I want to** connect my Discogs account and see, for every CD spine, candidate Discogs releases I can recognize, with manual search and a pasted release link for the ones auto-search misses, **so that** I can find the right release for every disc without Discogs rate limits ever losing work.

**This plan's slice:** in the same "Search Discogs…" dialog, the owner types an artist, title or catalog number, picks the right one of up to 25 results with covers, and adds it. Unknown numbers, failed searches and failed adds each get a plain message, and manual picks survive any new automatic search.

<objective>
Add free-text search to the Search Discogs dialog (the manual branch in search_spine and the dialog result covers), every remaining dialog state, and the tests that prove fetch-release, the search route modes, the candidates POST refusals and the manual-over-auto rule.

Purpose: DISC-06 (manual search); D-15 and D-16 (manual candidates survive automatic searches).
Output: the manual branch, the dialog cover route, the dialog's text-results, empty, loading and error states, fetch-release/search-route/candidates-route/store tests and verify-discogs-search steps (i) and (j).
</objective>
