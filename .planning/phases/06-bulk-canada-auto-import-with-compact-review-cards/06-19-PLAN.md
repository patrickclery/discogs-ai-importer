Gap coverage (every gap item maps to a task):
- No '#N' label and no corner number: Task 1
- The checkbox shares its row (with the Top match label and the pencil): Task 1

- top-match-row.tsx wraps to a varying number of lines (artifact): Task 2
- The contract is recorded: Task 3

Width facts behind the layout. The UI font is Geist Mono, about 7.2px per character at text-xs. At xl the card's content column is about 230px. The longest state badge, "Already in your collection", is about 221px. It fits alone on a row, but not beside a checkbox (16px + 8px gap) or a 36px icon button. So the state badge gets its own row, and the checkbox shares a row with the short match label and the pencil. Two warning badges often exceed 230px at xl ("Check label · 45%" plus "Fallback: US" is about 284px), so the warnings line wraps. The card is a CSS subgrid over six rows of the photo grid, so a wrapped warnings line (or a failed lookup's Retry import) grows that row for every card in the grid row. Nothing is cut off and the row still lines up.

Accessible names: the visible number is removed, but the number stays in the existing aria-labels (Select spine #N, Edit spine #N, Show less of spine #N) and the crop alt. Reasons: the Detailed and expanded cards still show #N, the skipped-duplicate line says "spine #12", and the toasts name spine numbers, so screen-reader users can cross-reference. SpineSelectCheckbox (shared with the Detailed card) is not changed.

Demo twin: src/app/spines/page.demo.tsx renders the same SpinesView → PhotoSection → CompactSpineCard, so there is no separate compact card in the demo. The change reaches the demo on its own, and no demo file changes.

Commands: pnpm is not on PATH. Use npx. The app runs on port 3001, never 3000.
