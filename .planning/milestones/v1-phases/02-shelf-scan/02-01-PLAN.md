## Phase Goal

**As the** owner cataloguing my CDs, **I want to** drop shelf photos and see every detected spine as a horizontal crop next to the AI-extracted fields, which I can correct, **so that** misreads are easy to see and fix and each photo costs exactly one Claude call.

(Derived from the ROADMAP Phase 2 Goal line and the PROJECT core value; the Goal line is not in user-story form. Flagged: run `/gsd-mvp-phase 2` to restate it if this framing is wrong.)

**This plan's slice (D-01 spike, the first task of the phase per the locked decision):** one real shelf photo goes through the production vision modules (decode, orient, model-tier resize, one `claude -p --json-schema` call, raw output recorded, parse, horizontal crops). Plan 02-02 measures the pixel space and read quality across photos, models and effort with the same modules; Plan 02-04 freezes the contract and puts it behind the scan job.
