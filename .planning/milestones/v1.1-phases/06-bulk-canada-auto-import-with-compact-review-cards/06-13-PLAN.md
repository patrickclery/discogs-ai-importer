Gap closure notes:
- The fallback tier needs its own versions answer. The D-01 request filters by country (`versionsQuery(country)` in src/server/discogs/versions.ts sends `country=Canada`), so the preferred answer never contains US versions. The orchestrator suggested reusing the same answer, but that is only possible by dropping the country filter. Without the filter, a large master's earliest 100 CDs (one page) can leave out the Canadian pressing, which would break the main path. So `choosePressing` takes a second, optional answer `fallbackVersions`, and `needsFallbackLookup` tells the job (Plan 06-16) when that second request is worth sending: only when the preferred answer had nothing usable and the top match is not already from the fallback country. The ranking function is the same one in both tiers.
- `bulk_items.outcome` is a TypeScript-only enum on a text column (drizzle/0004 has no CHECK), so adding an outcome needs no migration.
</context>
