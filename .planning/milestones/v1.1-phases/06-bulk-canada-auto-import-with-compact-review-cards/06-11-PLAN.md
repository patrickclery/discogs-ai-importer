src/demo/ops/bulk.ts:
- `BULK_STEP_MS = 1200`, `BULK_LOOKUP_MS = 600`.
- `startBulk(state, items, now): { status: 'ok'; runId; started; skipped } | { status: 'busy' } | { status: 'nothing'; skipped }`.
  - Answer busy when any item is still finding at now.
  - Validate picks against buildSpinesResponse(state, now).spines with the same eligibilityOf/topMatchOf rule and dedupe as the real eligiblePicks.
  - For each accepted pick i, in order, compute the outcome at readyAt:
    1. The latest import at readyAt failed with intent and its errorKind is neither not_found nor rejected: call demo retrySpine(state, spineId, readyAt) with outcome 'retried_earlier' (parity with D-20; the seeded spine 42 has no intent, so it takes step 3).
    2. countryMatch(top.country, run.country) is 'exact': use the top match, outcome 'preferred'.
    3. Canned pressing: push a DemoCandidate copied from the spine's recorded candidate with that releaseId (source 'pressing', id `demo-cand-${key}-pressing-${releaseId}`, addedAt readyAt) and use it, outcome 'preferred'. Canned fallback_no_master: use the top match with that outcome. Otherwise use the top match, outcome 'preferred' when the country is combined, else 'fallback_no_version'.
  - Then call startImport(state, { spineId, candidateId }, readyAt): ok → resolved with importId; duplicate → skipped 'duplicate' with dupSpineId; anything else → skipped 'changed'.
  - The demo duplicateOf result gains the holder's spineId for this. The demo 409 body is built field by field, so it does not change.
  - Each import is created with createdAt = readyAt, so the read model shows it only from then on (the store's lazy timestamp rule).

src/demo/ops/imports.ts startImport: answer already_confirmed when a demo bulk item for the spine is still finding at `now`, because its import is already scheduled.
